# fewu brand assets

The fewu mark is four rounded squares: three cream, one lime. The short square
in the bottom-right corner keeps the mark recognizable at small sizes.

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#191919` | App icon tile, dark surfaces |
| Cream | `#F6F3EC` | Primary mark, text on dark |
| Lime | `#C1E96D` | Accent, the top-right square |

## Files

- `fewu-mark.svg` — the mark on a transparent background. Use it on dark surfaces.
- `fewu-logo.svg` — the mark on the dark rounded tile. Use it on light or dark surfaces.
- `fewu-logo-animated.svg` — the animated tile used in the README. It respects
  `prefers-reduced-motion`.

Keep clear space around the tile equal to at least one square's width. Do not
rotate, outline, or recolor individual squares outside the palette above.
